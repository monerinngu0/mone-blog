`std::vector<T>` は、同じ型 `T` の要素を並べて保持するコンテナです。実行中に要素を末尾へ追加したり、取り除いたりできます。

## 要素を追加する

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> values = {10, 20};
    values.push_back(30);
    std::cout << values[0] << '\n';     // 10
    std::cout << values.size() << '\n'; // 3
}
```

`push_back()` は末尾へ要素を追加し、`size()` は現在の要素数を返します。添字は0から始まります。`operator[]` は範囲チェックをしないので、添字を `size()` 未満に収める必要があります。

## メモリ上の配置

通常の `vector<T>` の要素は連続したメモリ領域に置かれます。ただし `vector<bool>` は特殊化されており、この説明の対象外です。

追加する要素が確保済みの領域に収まらない場合、より大きい領域を確保して既存の要素を移すことがあります。この再確保では、元の要素を指していたポインタ・参照・イテレータは無効になります。

次の章では、現在の要素数を表す `size()` と、再確保せずに保持できる要素数を表す `capacity()` の違いを見ていきます。
